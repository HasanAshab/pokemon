Make an HTML, CSS, and JavaScript page that creates a beautiful and clean UI for comparing two JavaScript objects. The main function of the page is to visually compare the values of two given objects and highlight their differences in a structured and interactive layout.

Requirements:

1. **Two Object Inputs (Predefined & Editable):**

   * The page should have two side-by-side panels where two JavaScript objects can be entered or displayed.
   * Example objects:

     ```js
     const foo = {
       name: "Foo",
       age: 10,
       stats: {
         atk: 20,
         def: 30
       },
       types: ["Fire"],
       items: ["arrow"],
       a: 2,
     }
     const bar = {
       name: "Bar",
       age: 20,
       stats: {
         atk: 30,
         def: 15
       },
       types: ["Fire", "Water"],
       items: ["bow"],
       b: 1,
     }
     ```

2. **Comparison Result Section:**

   * The UI will have a central comparison result panel where each comparable field (numeric, string, array, object) will be listed.
   * The UI will show:

     * Numeric differences with absolute and percentage change.
     * Array differences as added/removed elements.
     * Object differences recursively.
   * Example display:

     ```
     Foo                          VS                        Bar
     age:                        →                         +10 (+100%)
     stats:
        atk:                     →                           +10  (+50%)
        def:                     →                           -15 (-50%)
     types:
          --                     →                             (+ Water)
     items:                       →                      (- arrow, + bow)
     ```

3. **Visual Indicators:**

   * Positive changes should be green (▲), negative changes red (▼).
   * Missing fields should be greyed out or have a warning icon.
   * Added/Removed array items should be color coded.
   * For nested objects, indentation and collapsible views should be present.

5. **Styling Guidelines:**
   * Use modern, minimalistic UI with soft shadows, rounded corners.
   * Highlight differences with smooth transitions.
   * Responsive layout supporting only mobile views.

6. **Optional Enhancements:**
   * Allow field-wise comparison selection (only compare selected keys).
   * Highlight nested differences with animated expansion.
